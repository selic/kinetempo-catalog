# Инструкция для авторов — упражнения и комплексы для Kinetempo

Полная версия с таблицами полей — в [AUTHORING.md](AUTHORING.md) (англ.). Здесь — суть и порядок действий.

## 1. Модель

- **Упражнение** — это *шаблон повтора*, повторённый N раз. Повтор = список **шагов**; у шага есть **тон**
  (что делает тело), длительность в миллисекундах и необязательная подпись.
- **Комплекс** (в файле `complex`) — упорядоченный список упражнений с отдыхом между ними.
- Приложение играет свой звук на каждый тон, «тикает» последние 3 секунды активных шагов и показывает
  текущий шаг на экране блокировки.

Тоны: `squeeze` (напрячь, ничего не двигается), `lift` (поднять), `hold` (держать), `release` (опустить),
`move` (движение — скольжения, «насосы»), `timer` (просто отсчёт, без повторов), `rest` (отдых).
В повторе должен быть хотя бы один не‑`rest` шаг; хвостовой `rest` в последнем повторе подхода приложение пропускает само.

Типовые схемы: изометрия `squeeze 8 с → rest 4 с`; поднять‑задержать‑опустить
`lift 2 → hold 5 → release 2 → rest 3`; динамика `lift 2 → release 2`; таймер `timer 300` с `reps: 1`;
скольжения `move 4 «Внутрь» → move 4 «Наружу»`.

## 2. Структура папок

```
publishers/<id-издателя>/publisher.json
publishers/<id-издателя>/programs/<slug>.<локаль>.kinetempo.json
publishers/<id-издателя>/exercises/<slug>.<локаль>.kinetempo.json
```

`<id-издателя>` — строчные латинские буквы, цифры, дефисы; должен совпадать с `id` в `publisher.json`.
Локали: `en`, `ru`, `ro` — один язык на файл, переводы отдельными файлами с тем же slug.

## 3. Порядок действий

1. Сделайте форк репозитория, создайте `publishers/<id>/publisher.json` (тип: `clinic`, `physiotherapist`,
   `doctor`, `organisation`, `individual`; `verified` оставьте `false` — его ставят мейнтейнеры после проверки сайта/реестра).
2. Соберите комплекс в приложении и экспортируйте файл (Поделиться → Экспорт в файл) — это уже готовый документ.
   Либо напишите JSON по примеру в [examples/](../examples/).
3. Положите файл в `programs/` (есть `complex`) или `exercises/` (одно упражнение), назовите `<slug>.<локаль>.kinetempo.json`.
4. Добавьте блок `catalog`: `tags`, `bodyParts`, `level` (`rehab` | `beginner` | `intermediate` | `advanced`),
   `source` (протокол/документ), `reviewedBy` (кто проверил), `license` (по умолчанию CC‑BY‑4.0).
5. `npm install && npm run validate` — проверка схемы и ссылок. Откройте pull request.
   После слияния программа появится в приложении (вкладка «Библиотека») через несколько минут.

## 4. Правила содержания

- Это не медицинская рекомендация; программы под конкретного пациента должны быть помечены в описании.
- Опишите, как выполнять, чего избегать и когда остановиться (острая боль, отёк, температура).
- Только ссылки на видео/анимации (YouTube, Lottie JSON, GIF) — файлы не принимаются.
- Никаких персональных данных пациентов.
- `updatedAt` меняйте при каждой правке — по нему приложение предлагает обновление.

## 5. Скилл для Claude / Codex
